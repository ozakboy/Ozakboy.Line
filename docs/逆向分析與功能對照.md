> 日期:2026-10-27。分析對象為 `docs/` 內三個 .nupkg(皆無公開原始碼),以 dotnet 8 + ILSpy 9.1 反編譯成 C# 後逐檔閱讀。

## 1. 三個套件一句話定位

| 套件 | 作者 / 年代 | TFM | 規模 | 定位 |
|---|---|---|---|---|
| **LineBotSDK 2.18.45** | 董大偉(isRock),2018 起持續更新到 2024+ | net45 + netstandard2.0 | 108 檔 / 4,400 行 / 120 型別 | 台灣最普及的 LINE Bot SDK。靜態 `Utility` + `Bot` 門面,涵蓋面最廣(Messaging、Rich Menu 含 alias / batch、Login v2.1、LIFF、Notify、洞察) |
| **LineBotExtension 1.18.0** | Denots,2018 | net461 | 17 檔 / 4,900 行 / 249 型別 | 不是 API 包裝,而是一個 **Bot 框架**:`IBot` 事件回呼、Flex 強型別模型、宣告式驗證、快取、Quartz、Postback 協定、Rich Menu 宣告式部署 |
| **LineBot.SDK 0.2.0** | Martin Hsu,2018 | net45 | 40 檔 / 1,160 行 | 薄包裝:單則 push、Rich Menu 9 方法、LIFF 5 方法。無 reply、無驗簽、全同步 |

三者共同點:**Newtonsoft.Json、全同步或無 CancellationToken、每次 new WebClient / HttpClient、例外是裸 `System.Exception`、無 DI、無介面、無測試注入點**。這些是我方已經做對的地方,不需要回頭。

## 2. 他們做了哪些元件(濃縮版)

### LineBotSDK(isRock)
- **送訊息**:push / reply / multicast / broadcast / validate(push, reply)/ loading animation;Flex 只能用 JSON 字串(`*WithJSON`)
- **訊息模型**:text / image / video / audio / location / sticker / imagemap(+video)/ template 四種;`Sender`、`QuickReply` 六種子類;**無** Flex 模型、無 emoji / mention 送出
- **動作**:uri / message / postback(含 `inputOption` / `fillInText`)/ datetimepicker / camera / cameraRoll / location / clipboard;**無** richmenuswitch
- **Webhook**:`Utility.Parsing` 扁平 POCO(`Event` 有 beacon / link / joined / left 欄位)、`SignatureValidation(ControllerBase)`、`LineWebHookControllerBase` 繼承式基底
- **Rich Menu**:全套,含 alias 五個、bulk link / unlink、**batch(replace / unlink / unlinkAll)+ validate batch + progress**
- **資料**:profile、group / room(summary、count、member ids 不可翻頁、member profile、leave)、bot info、content 下載
- **配額 / 洞察**:quota、consumption、**delivery per type(reply / push / multicast / broadcast)**、insight message delivery、followers、demographic(JST 日期轉換)
- **Login v2.1**:只有換 token、profile、friendship 三個;**無**授權網址 / PKCE / refresh / revoke / verify / id_token
- **其他**:**webhook endpoint 查 / 設 / 測試**、**短期 channel access token(舊 v2)**、link token(標 Obsolete、回傳丟掉)、**LIFF**(add / list / delete,update 未實作)、Notify(已終止)
- net45 版獨有:`Conversation.InformationCollector<T>`(逐題收集輸入的對話狀態機)、QnA Maker

### LineBotExtension(Denots)
- **框架層**:`BotHelper.IBot` 抽象類(10 個事件回呼:message、4 種 postback、follow / unfollow / join / leave、beacon)、`RequestHelper.Recieved(id, request)` 一個端點掛多個 channel(`BotDataIdMap`)、測試 / 維護模式 + 管理員白名單 + 例外直接回給管理員
- **Flex 強型別模型**(本套件最大區塊):bubble / carousel 容器、box / text / image / button / icon / separator / spacer / filler 元件、styles;以標記介面在編譯期限制 baseline box 只能放 text / icon / filler;列舉 → 字串對應(`3xl`、`1.91:1`)。**只到 2018 規格**:無 span / video / padding / cornerRadius / offset / position / justifyContent
- **宣告式驗證**:`ExamineHelper` 七種 Attribute(Required / Range / Length / Count / Url(https) / Color / Contains)+ 反射,建構工廠 `._Text(...)` 時即 `.Examine()`,收集全部錯誤一次丟;含 **carousel 跨欄一致性**檢查
- **Postback 協定**:型別化 payload(key / search / cache / expired)、**data > 300 字自動轉存 MemoryCache 以 GUID 代替**、分頁「上一頁 / 下一頁」按鈕產生器、`{{path}}` 範本注入
- **快取**:`ICache`(可換 Redis)五個固定鍵整包字典、永不過期;使用者 / 群組成員 / Rich Menu 資料
- **Quartz**:只用來每日 / 每月重建 `BaseData`,**沒有排程推播**
- **Rich Menu 宣告式部署**:啟動時列出 → 全刪 → 依 `GetRichMenuMap()` 重建 → 自動 link 既有使用者
- **Imagemap**:站台自己提供圖片路由,依 LINE 要求的寬度動態縮圖並快取(System.Drawing)
- **文字指令路由**:精確比對 + 正則具名群組擷取參數

### LineBot.SDK(Martin Hsu)
- 7 個 `PushXxxMessage`(單則 push)、Rich Menu 9 方法(含 DeleteAll)、LIFF 5 方法(add / update view / list / delete / deleteAll)
- Webhook 只有 POCO,無解析入口、無驗簽;`UserUtility` 空殼、`TemplateMessageBase` 無子類

## 5. 不值得學的(已確認,不要被它們帶偏)

- 字串拼 JSON、`Replace("'", "\"")`、`dmy://dummy` 假值再刪欄位
- 靜態 `Utility` 每個方法帶 token、`WebClient` / 每次 `new HttpClient()`、全同步、`.Result`
- 裸 `Exception` 塞 HTTP 本文;Validate 吞例外回 `false`
- `LineWebHookControllerBase` 繼承式設計(綁 MVC、不驗簽、不回 200)
- LINE Notify(2025-03-31 已終止)、Login v1、Trial Bot 端點
- 扁平聯集式 `Event` / `Message`(非 nullable 數值分不出「無」與「零」)
- Rich Menu 啟動時全刪重建(會刪掉 OA Manager 手建的選單)
- `System.Drawing`、Quartz 2.x + `async void` Job、永不過期的整包字典快取、`MemoryCache.Default` 繞過抽象
- 130 個巢狀型別的 god class、三套同名 Action 階層、`_Xxx()` 工廠命名
- 手寫 URL regex(擋掉 `tel:`、`line://`、大寫主機)
- QnA Maker、net45 專屬對話狀態機(概念可參考,程式碼不移植)
